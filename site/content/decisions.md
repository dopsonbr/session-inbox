# Decisions

Every implementation decision, with the reason for it. This page is generated from [`DECISIONS.md`](https://github.com/dopsonbr/session-inbox/blob/main/DECISIONS.md) in the repository each time the site is built. Where it disagrees with the original spec, this record wins, because it records what was learned along the way.

Each decision has its own anchor. Link straight to one, like [G-014](#G-014), by adding its id to the page address.

The letters say which area a decision belongs to: **G** general, **C** contracts, **D** daemon, **H** hook and ops, **U** UI, **S** shell and **P** the Phase 0 spike.
